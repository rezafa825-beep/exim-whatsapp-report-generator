EXIM WhatsApp Report Generator

Baca file Excel secara lokal, pilih dokumen, atur jalur, lalu buat laporan siap salin ke WhatsApp.

1. Unggah file Excel CEISA

Belum ada file Excel yang ditambahkan.

Pilih satu file, lalu pilih file berikutnya untuk menambahkannya. File diproses di browser ini; jangan unggah file Excel perusahaan ke repository GitHub.

2. Filter laporan

Default mengikuti hasil sistem: dokumen Keluar = Customer, dokumen Masuk = Supplier. Dropdown Customer/Supplier hanya mengubah keterangan pada laporan; pengambilan nama pihak dan filter tetap mengikuti pemetaan data otomatis yang sudah ada.

3. Pengaturan jalur

Semua dokumen HIJAU secara default. Centang nomor pendaftaran yang harus menjadi MERAH.

Unggah Excel untuk menampilkan daftar dokumen.

4. Pengecualian nomor daftar

Centang nomor daftar yang tidak ingin dimasukkan ke laporan, atau ketik nomor secara manual. Pemilihan ini tidak menghapus data Excel.

Unggah Excel untuk menampilkan nomor daftar.

Belum ada nomor daftar yang dikecualikan.

5. Pratinjau laporan WhatsApp

Versi pengembangan · Pemrosesan Excel dilakukan di browser · Periksa hasil sebelum dikirim.
