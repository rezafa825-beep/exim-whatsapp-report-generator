EXIM WhatsApp Report Generator

Baca file Excel secara lokal, pilih dokumen, atur jalur, lalu buat laporan siap salin ke WhatsApp.

1. Unggah file Excel CEISA

File diproses di browser ini. Jangan unggah file Excel perusahaan ke repository GitHub.

2. Filter laporan

Mode Otomatis mengikuti alur dokumen. Pilihan Customer atau Supplier dapat diubah manual. Daftar nama diambil dari Sheet ENTITAS.

3. Pengaturan jalur

Semua dokumen HIJAU secara default. Centang nomor pendaftaran yang harus menjadi MERAH.

Unggah Excel untuk menampilkan daftar dokumen.

4. Pratinjau laporan WhatsApp

Versi awal · Pemrosesan Excel dilakukan di browser · Periksa hasil sebelum dikirim.
